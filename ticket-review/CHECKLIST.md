# Review Checklist

ticket-review 품질 축에서 항목별로 점검. 각 항목의 `→` 는 리뷰 의견의 배정 블록.

## 포인터
- 역참조 전 null 체크. 누락 시 앱 종료 → 결함
- 처리: early return + Error 로그
- 같은 형태의 누락은 전수 확인. 한 건만 지적하고 넘기지 않음

## 상수
- `k` 접두어 금지 → 기타 수정사항
- 전역 스코프 금지. 단일 클래스 전용이면 클래스 내부 → 기타 수정사항
- 여러 클래스 공유 상수는 configuration/setting 구조체·클래스에 모음 → 검토 필요 사항

## 루프
- 손으로 쓴 `for` 대신 `std::erase_if` / `count_if` / `any_of` / `none_of` / `all_of` 등 표준 알고리즘 → 검토 필요 사항 (제안 수준, 강제 아님)

## 주석
- 코드가 하지 않는 동작을 적은 주석은 정정. 동작 영향 없어도 대상 → 기타 수정사항
- 완료된 Issue · PR 번호를 주석에 남기지 않음. 영속하는 설계 결정으로 오인됨 → 기타 수정사항
- 주석은 최소화. 코드가 동작을 스스로 설명하도록 네이밍 → 검토 필요 사항

## 네이밍
- 이름만으로 역할이 읽혀야 함. 주석으로 보완하는 이름은 재고 → 검토 필요 사항
- 어려운 단어·생소한 약어 금지. 흔한 단어 우선 → 검토 필요 사항

## 오류 메시지
- 실패한 경로·값을 메시지에 포함. 실제 원인과 다른 문구 금지 → 기타 수정사항
